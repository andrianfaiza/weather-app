# Weather App
A sleek and responsive web application that provides real-time weather updates for cities across the globe using the OpenWeatherMap API.

## Features
* **Real-time Weather Data:** Provides current temperature and weather conditions.
* **Air Quality Index (AQI):** Tracks pollutants including PM2.5, SO2, NO2, and O3 for health safety.
* **5-Day Weather Forecast:** Detailed outlook for the upcoming days.
* **Hourly Forecast:** Visualizes weather changes throughout the day in the "Today at" section.
* **Sunrise & Sunset Tracker:** Accurate times for sunrise and sunset.
* **Advanced Highlights:** Detailed metrics such as Humidity, Pressure, Visibility, and "Feels Like" temperature.
* **Global Search:** Easily search for weather information by city name.
* **Modern Dark UI:** A clean, professional dashboard design for better readability.

## Tech Stack
* HTML5 & CSS3: For structure and modern styling.

* JavaScript (ES6+): For asynchronous API fetching and DOM manipulation.

* API: OpenWeatherMap API

## Getting Started
Follow these steps to get a local copy up and running:

1. Clone the Repository
Bash
```git clone https://github.com/your-username/weather-app.git```
```cd weather-app```

2. Get Your API Key
Go to <a href='https://openweathermap.org/'>OpenWeatherMap</a> and create a free account.

Navigate to the API Keys tab and copy your unique key.

3. Configuration
Open your JavaScript file in ```assets/script/script.js``` and replace the placeholder with your actual API key:

JavaScript
```const API_KEY = "API_KEY_IN_HERE";```

4. Run the App
Simply open index.html in your web browser.
